Amazon Clone 🛒

A frontend clone of the Amazon website created using HTML and CSS as a web development practice project.

🚀 Features

- Amazon-style navigation bar
- Search bar
- Product/category sections
- Responsive layout
- Amazon-inspired homepage design
- Hover effects and styling

🛠️ Technologies Used

- HTML5
- CSS3

🎯 Purpose

This project was created to improve my understanding of HTML, CSS, layouts, Flexbox, navigation bars, and frontend web development.
